# NovaTech — Product Landing Page

Project 04 for the Tap Academy frontend assignment. A responsive landing page for the fictional NovaTech Pulse Pro wireless headphones.

## Features
- Responsive, mobile-first layout
- Product hero section and calls to action
- Feature cards and specifications table
- Interactive testimonial carousel
- Demo purchase interaction (does not process real orders)
- Mobile navigation menu
- Semantic HTML and accessible labels

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.
